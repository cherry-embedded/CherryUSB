# Note

> To compile support for CherryUSB on WCH chips, please refer to the repository: https://github.com/Links0617/wch-support-cherryusb.git

## Support Chip List

## USBFS

- CH32L103
- CH32M103
- CH32F20x
- CH32V20x
- CH32V30x
- CH32V31x
- CH32H417

## USBHS

- CH32V205
- CH32V4x7
- CH32H417
- CH32X305
- CH58x
- CH645
