Security Advisories and CVE Catalog
===================================

Report a vulnerability
----------------------

Please follow the repository's
`security policy <https://github.com/cherry-embedded/CherryUSB/security/policy>`_
or email ``1203593632@qq.com``.

Published advisories
--------------------

The authoritative GitHub advisory list is available at
`CherryUSB Security Advisories <https://github.com/cherry-embedded/CherryUSB/security/advisories>`_.

No entries have been added to this catalog yet. This does not imply that no
vulnerabilities or external advisories exist. Add entries only after the
maintainers have confirmed the issue and approved public disclosure.

Information required for each entry
-----------------------------------

* Advisory title and publication date.
* GHSA identifier and public advisory URL, if assigned.
* CVE identifier, if assigned; an advisory may be published without a CVE.
* Affected releases or commits and any required build configuration.
* Fixed releases and full fix commit identifiers.
* Affected host/device classes and controller drivers, where applicable.
* Impact, trigger conditions, and available workarounds.
* CWE and CVSS version/vector/score, if assessed.
* Reporter attribution, with the reporter's consent.

Do not infer an affected version range from the fix commit alone, invent CVE
identifiers, or treat an internal code review finding as a published advisory.
