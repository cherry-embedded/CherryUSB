安全公告与 CVE 目录
===================

报告安全漏洞
------------

请按照仓库的
`安全策略 <https://github.com/cherry-embedded/CherryUSB/security/policy>`_
提交报告，或发送邮件至 ``1203593632@qq.com``。

已公开的安全公告
----------------

GitHub 上的正式公告请查看
`CherryUSB Security Advisories <https://github.com/cherry-embedded/CherryUSB/security/advisories>`_。

本目录目前尚未添加公告条目。这不代表不存在漏洞或外部公告。
仅在维护者确认问题并决定公开披露后，才将对应条目加入本目录。

每条公告需要的信息
------------------

* 公告标题和发布日期。
* GHSA 编号及公开公告链接（如已分配）。
* CVE 编号（如已分配）；公告也可以不包含 CVE 编号。
* 受影响的版本或提交，以及必要的构建配置。
* 修复版本和完整的修复提交编号。
* 涉及的主机/设备类和控制器驱动（如适用）。
* 影响、触发条件，以及可用的缓解措施。
* CWE，以及 CVSS 版本、向量和评分（如已评估）。
* 经报告者同意的署名。

不要仅依据修复提交推断受影响的版本范围，不要编造 CVE 编号，
也不要将内部代码审查发现直接视为已公开的安全公告。
